AI-powered marine oil spill detection, drift prediction, and AIS vessel attribution.

This project combines:



\- Satellite imagery

\- Oil spill detection

\- AIS vessel telemetry

\- Vessel anomaly detection

\- Hydrodynamic drift reconstruction

\- Historical AIS correlation

\- Suspect ranking

\- Interactive GIS dashboard

\- Automated alert dispatch
